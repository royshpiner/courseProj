# Project instructions

- This is a self-directed C# and .NET learning project. The learner owns the implementation, verification, documentation, and Git workflow. Use this workspace as read-only context for answering their questions until they explicitly change that arrangement.
- Answer the question asked using plain language for C# and .NET concepts. Give hints, examples, code, commands, or a review when the learner asks for that kind of help.
- At the start of a new chat, read [Current progress](docs/ASSIGNMENT.md#current-progress) and the [implementation plan](docs/ASSIGNMENT.md#implementation-plan). Inspect relevant files and Git status when needed to ground an answer. Refer to the assignment PDF for exercise details when available.
- `courseProj.sln` contains the .NET 11 `Backend` console app and the separate `Backend.Tests` xUnit project.
- Track `AGENTS.md`, `docs/ASSIGNMENT.md`, and `AI_NOTES.md` in Git so the learner can resume with an agent from another checkout. Edit [AI_NOTES.md](AI_NOTES.md) only when the learner explicitly asks.
