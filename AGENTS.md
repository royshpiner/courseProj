# Project instructions

- This is a self-directed C# and .NET learning project. The learner owns implementation, verification, the assignment README, and the Git workflow. Use the workspace as read-only context for code unless the learner explicitly asks for an edit.
- Answer the question asked using plain language for C# and .NET concepts. Work in small steps and explain each code example. Write out the type in constructor calls, such as `new ExchangeSession()`.
- At the start of a new chat, read [Current progress](docs/ASSIGNMENT.md#current-progress) and the [implementation plan](docs/ASSIGNMENT.md#implementation-plan). Inspect relevant files and Git status when needed to ground an answer. Refer to the assignment PDF for exercise details when available.
- Keep [Current progress](docs/ASSIGNMENT.md#current-progress) up to date when implementation or verification status changes. Record what has been verified and the next unfinished step so the learner can resume in a new chat.
- `courseProj.sln` contains the .NET 11 `Backend` console app and the separate `Backend.Tests` xUnit project.
- Track `AGENTS.md`, `docs/ASSIGNMENT.md`, and `AI_NOTES.md` in Git so the learner can resume with an agent from another checkout. Edit [AI_NOTES.md](AI_NOTES.md) only when the learner explicitly asks.
